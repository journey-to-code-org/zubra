# Security policy

Please report vulnerabilities privately through this repository's GitHub security advisories ("Report a vulnerability" on the Security tab), not in a public issue. The trust model, and what the compiler and runtime guarantee, is described in `docs/security.md`.

The latest 6.x release receives security fixes, for 18 months after 6.0.0 (see [docs/stability.md](docs/stability.md#the-6x-long-term-support-line)). Upgrade within 6.x to get them: a 6.x release never breaks anything Stable. 5.x receives no further fixes.
